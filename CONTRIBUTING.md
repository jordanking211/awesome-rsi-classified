# 贡献与纠错 / Contributions and corrections

本项目整理 RSI 及相关自改进技术。欢迎通过 Issue 或 Pull Request 补充遗漏方法、纠正分类和更新证据。

每项建议请提供：

1. 方法名称、原论文或官方资料链接。
2. 主要修改对象，以及涉及的其他对象。
3. 支持分类的证据：源码仓库、提交 SHA、文件／函数和写回或训练路径；无法确认实现时明确标为论文层判断。
4. 核查范围与日期：仅资料阅读、关键源码静态核查或实际复现。实际复现请提供版本、配置、命令与结果。
5. 修改理由和已知限制，包括第三方实现、训练／运行阶段差异，以及训练的是哪个模型。

同步修改中英文条目，保留现有分类锚点；新增方法时更新计数并区分方法数与仓库数。不要因项目名称包含“self-improving”或“RSI”就推断递归性，也不要把论文报告的性能写成维护者已复现的结果。纠错优先提供原始证据。

## English

This project indexes RSI and related self-improvement techniques. Use an issue or pull request to propose missing methods, classification corrections, or evidence updates.

Include the method name and primary sources; its primary and additional modification targets; repository, commit, file/function, and write-back or training evidence where available; the inspection scope and date; and the reason for the change with known limitations. Label paper-only conclusions explicitly. For reproductions, provide versions, configuration, commands, and results.

Update both language editions, preserve category anchors, and update counts when adding methods. Distinguish method counts from repository counts, author implementations from third-party implementations, and training from runtime changes. A project name does not establish recursion; a paper's reported performance does not establish a maintainer reproduction.
